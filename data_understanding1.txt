# Disaster Type Prediction – Data Understanding

## Objective
The objective of this project is to analyze the EM-DAT disaster dataset 
and understand its structure before building a machine learning model 
to predict disaster types.

## Dataset Information
- Source: EM-DAT International Disaster Database
- Total records: 17756
- Total features: 47
This notebook focuses on exploratory data analysis (EDA).

## Dataset Dimensions
The dataset contains 17756 rows and 47 columns.
Each row represents a recorded disaster event.
Each column represents a feature describing the disaster.

## Target Variable: Disaster Type
There are 15 unique disaster types in the dataset.

## Class Imbalance Analysis
The most frequent disaster type is 39.78%.
The least frequent disaster type is 0.01%.
The dataset appears to be: Highly Imbalanced
This imbalance may affect model performance and 
techniques such as class weighting or resampling 
may be required.


# Summary of Data Understanding
- Total records: 17756
