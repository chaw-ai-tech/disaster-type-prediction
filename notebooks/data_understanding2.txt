DATA PREPARATION AND FILTERING PROCESS
======================================

1. Objective
------------
The objective of this data preparation step is to filter the dataset 
to include only the five selected disaster types and prepare the data 
for further analysis and modeling.

2. Filtering Selected Disaster Types
-------------------------------------
The original dataset contained 14 disaster categories. 
For focused analysis, only the following five disaster types were selected:

- Flood
- Storm
- Earthquake
- Epidemic
- Extreme temperature


3. Dataset Size Before and After Filtering
-------------------------------------------
After filtering, the total number of records was reduced. 
records = 9205
features = 47
This ensures that the analysis is concentrated only on the selected 
disaster categories.

4. Class Distribution Analysis
-------------------------------
The distribution of the selected disaster types was examined using 
value counts and percentage calculations.

The imbalance ratio was computed as:

    Imbalance Ratio = (Maximum Class Count) / (Minimum Class Count)

The calculated imbalance ratio was approximately 7.46.

This indicates severe class imbalance, as the largest class contains 
about 7.5 times more samples than the smallest class.


5. Conclusion
-------------
The dataset has been successfully filtered and analyzed. 
The data is now ready for feature engineering, model training, 
and imbalance handling techniques.
